Written below is a brief summary of the skills I picked up during my time at Kenna

Employer Description

Kenna is a "one stop shop" for businesses, meaning it provides a large suite of services for its clients, including applications development, accounts, marketing, and more. Kenna is a child company of Stagwell, in charge of calculating incentives and rewards for farmers to recieve if they meet the right criteria. The division I was in focused on creating web applications to assist with the calculation of incentive payments, and displaying information about each client.

Goals

At my fourth term at Kenna, I set the following goals: 1. Develop my problem solving skills to tackle each new problem uniquely in a way that best fits the situation. 2. Continue to develop my SQL skills. 3. Develop my knowledge on company procedures and standard year over year work.

Job Description

The first project I worked on during my fourth term at Kenna was builing a PDF processing tool for the data team. This tool automates some of their work in order to save time and lighten their busy schedules. My tool was ran using an AWS Lambda function and was written in Python. In this project especially I was granted alot of freedom in my implementation methods, applying my knowledge of the Kenna backend systems to decide on the best course of action that keeps things simple for the user, given that not all files need additional processing.


After that I worked on some minor optimizations for one of Kennas existing tools. Two SQL queries in particular were taking around 15-20 seconds to run, and I was able to optimize the SQL query and get it running in just 300ms. I did this by adding indexing to the tables and refactoring the query, mainly changing the join order of the tables.


My last project was assisting in a new project for Kenna, a file manager for their UK operations. I assisted in developing the API for this tool as well as some of the frontend. I added functionality for creating attachments and storing them in S3, deleting attachments, and modifying attachments primarily.

Conclusion

In conclusion, during my time working for Kenna, I was able to learn a lot about a more corporate structure of programming, as well as gain valuble industry skills.
